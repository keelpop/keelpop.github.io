# 息を殺して — Breathless

暗闇を音で測り、自分の鼓動を殺して化け物をやり過ごす、スマホ向けブラウザホラーゲーム。

**遊ぶ:** https://keelpop.github.io/breathless/ （🎧 イヤホン推奨）

## Dark Echo のどこを直したか

同ジャンルの先行作 Dark Echo のレビューで繰り返し指摘されていた不満を、実装で潰している。

| レビューでの指摘 | このゲームでの答え |
|---|---|
| 「総当たりで、全部わかるまで何度も**最初からやり直す**」<br>([148Apps](https://www.148apps.com/dark-echo/dark-echo-review/)) | **チェックポイント制**。化け物のいない場所を通ると自動で記録され、死んでも描いた地図と拾った遺物はそのまま残る。ステージ丸ごとやり直させない |
| 「**赤い危険がどれだけ近いか見えないまま死ぬ**ことが多かった」<br>([Metacritic](https://www.metacritic.com/game/dark-echo/)) | **危険の方向表示**。近くの化け物がいる方向だけ画面の縁がほのかに滲む。位置は教えないが「どっちから来ているか」は常にわかる |
| 一発死の理不尽さ | **掴まれても即死しない**。0.95秒の猶予に画面を振れば振りほどける。失敗して初めて死ぬ |
| 「そろそろ忍び歩く場面が退屈で、しかも**画面を必死に連打**し続ける必要がある」<br>([Pocket Gamer](https://www.pocketgamer.com/dark-echo/review/)) | **連打なしのドラッグ移動**。倒した量がそのまま速度になり、指を置いておくだけで歩き続ける |
| 「**8方向しか向けず**、後半はクリア不能になりかねない」<br>([Steam](https://steamcommunity.com/app/368650/discussions/0/490124466466049011/)) | **360度**の移動と、正面へ細く飛ぶ舌打ちの向きも360度 |
| 「毎回、地形を測り直す」 | **記憶の地図**。測った壁は刻まれて残り、ゆっくりとだけ薄れる |
| 「一部ステージが非常に長く**中だるみ**する」<br>([アプリゲット](https://appget.com/appli/view/65893/)) | 全5ステージ、1ステージ数分。長い迷路もチェックポイントで再挑戦が軽い |
| 赤と白の2色は、色覚によっては見分けにくい | **色覚対応パレット**（青・黄・白）を設定で選べる。加えて**明るさ調整**（60〜180%）で、明るい場所でも遊べる |

救済が過剰だと感じる人向けに、設定で「危険の方向表示 / チェックポイント / 振りほどき」を
個別に切れる。3つとも切ると原作に近い一発死の緊張になる。

## このゲームの軸

「暗闇＋音の反響」というジャンルの中で、このゲームが賭けているのは次の3つ。

**1. 音は消えるが、地形は憶えている**
返ってきた音が当たった壁面は、壁に沿った短い線分として「記憶の地図」に刻まれる。
何度も測った壁ほど濃くなり、しばらく経つとゆっくり薄れていく。
遊びの中心は反射神経ではなく、暗闇を少しずつ測って地図を描く作業になる。

**2. 自分の体が音源になる**
鼓動は止められない。化け物が近いほど、走るほど恐怖が上がり、心拍が速くなり、
その音が届く範囲も広がる。じっとしていても安全ではない。

**3. 息を止めれば静かになるが、長くは保たない**
〈息〉を押している間は鼓動も足音も漏れず、世界の音がこもって自分の心臓だけが近くなる。
かわりに歩みは遅く、息は尽きる。尽きた瞬間、大きく喘いで居場所を晒す。

## あそびかた

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面をドラッグ（大きく倒すと走る） | WASD / 矢印キー、Shiftで走る |
| 舌打ち | 短くタップ | スペース |
| 呼ぶ | 〈呼〉ボタン | E |
| 息を止める | 〈息〉ボタンを押し続ける | F を押し続ける |
| 一時停止 | 右上のボタン | Esc |
| 振りほどく | 掴まれたら画面をすばやく振る | 移動キーを連打 |

- **舌打ち**：正面へ細く鋭く飛ぶ探査音。遠くまで届くのにほとんど聞かれない。地図を描く主力
- **呼ぶ**：全方位へ遠くまで届く。一気に広く見えるが、あちらにも同じだけ届く
- 水たまりは大きな音を立てる。走ると聞こえる範囲は倍以上になる
- <span>橙の波</span>＝化け物。姿は一切見えず、あちらの足音だけが位置を伝える。
  **時々立ち止まって耳を澄まし、完全に無音になる**ので、静かになったら近い
- <span>緑の波</span>＝遺物と出口。遺物を全て拾ってから出口へ

## 構成

```
breathless/
  index.html      画面構成とUI
  css/style.css
  js/audio.js     Web Audio API による効果音の合成（音声ファイルなし）
  js/levels.js    ステージデータ（tools/genlevels.py が生成）
  js/game.js      ゲーム本体
```

外部ライブラリ・アセットは一切なし。すべて Canvas 2D と Web Audio で生成している。

### 縦持ち前提のカメラ

視界は画面の**短辺**に 9.5 マスが収まる倍率で決まる。縦持ちでは横9.5マス・縦20マス前後が
映るので、縦画面でも通路の先が読める。320px 幅の小型端末から横向きまで、
HUD が重ならないことを確認している。

### 描画

世界サイズのオフスクリーンキャンバスを2枚重ねている。

- **mem**（記憶の地図）— 反射点を壁に沿った線分として上書き合成で焼き、
  30フレームに一度だけごく薄く暗くする。加算合成にすると何度も当たった壁が
  白く飛ぶので、上書き合成で色に収束させている。歩いた跡も薄く残る
- **live**（いま鳴っている音）— 波面を点で描き、毎フレーム速く暗くする

live の更新は画面に映っている矩形に限定し、スクロールで新しく現れた帯だけを
消している。周辺減光は毎フレーム生成すると重いので焼いたキャンバスを使い回す。

### 音

足音や舌打ちを出すたびに数十本の「音の粒子」を飛ばし、壁で反射させて減衰させる。
化け物はプレイヤーが立てた音の大きさに応じた半径でそれを聞きつけ、
最後に音がした場所へ BFS のフローフィールドを辿って向かう。
到着して何もいなければ、そこで立ち止まって耳を澄ます。

効果音は実行時合成のみ（足音・水音・舌打ち・叫び・喘ぎ・咆哮・心音・洞窟の残響）。
息を止めている間は master にローパスをかけて世界の音をこもらせ、
心音だけはその外側に繋いで、体内の音として近くに残している。

### ステージの編集

`breathless/js/levels.js` は手で編集せず、`tools/genlevels.py` を書き換えて再生成する。
生成時に各ステージの寸法と「開始地点 → 遺物 → 出口」の到達可能性を検証している。

```sh
python3 tools/genlevels.py
```

記法: `#` 壁 / `.` 床 / `~` 水 / `P` 開始地点 / `E` 出口 / `*` 遺物 /
`M` 徘徊する化け物 / `S` 眠っている化け物
