Anthropic の AI セキュリティツール「Claude Security」のまとめ(公式製品ページ・関連情報より/2026年7月時点)

Claude Security とは

Claude Security は、Anthropic が提供する AI 駆動の脆弱性検出・修正支援ツール。Claude がコードベース全体をスキャンし、発見した脆弱性を自ら検証したうえで、人間がレビュー・承認できる修正パッチを提案する。2026年4月30日にパブリックベータとして公開された。

基本の流れ:スキャン → 検証 → 修正提案
  • スキャン — コードの構造、コンポーネント間の連携、データフローを人間のセキュリティ研究者のように読み解いて解析する
  • 検証 — すべての検出結果に対して「敵対的検証(adversarial verification)」を実施。Claude が自分の検出結果に反論を試み、誤検知(False Positive)を減らす
  • 修正提案 — 確認済みの脆弱性に対してパッチを提案。適用するかどうかは人間がレビューして判断する(自動マージはされない)

検出対象の脆弱性

パターンマッチング型の従来ツールが見逃しやすい、高深刻度の脆弱性に重点を置いている。

  • メモリ破壊(memory corruption)
  • インジェクション系の欠陥(SQLインジェクションなど入力起因の脆弱性)
  • 認証バイパス・アクセス制御の不備
  • 暗号・シークレット管理の問題
  • 複雑なロジックエラー(複数ファイルにまたがる依存関係を追跡して発見)

Claude Code プラグイン版

2026年7月には、ターミナルで動く Claude Code 向けの「Claude Security プラグイン」もベータ公開された。開発ワークフローを離れずに、コミット前の変更やコードベース全体をスキャンできる。

インストール

/plugin install claude-security@claude-plugins-official

組織の管理者は claude.ai の管理コンソール(Claude Code 設定)から有効化する。

コマンド:/claude-security
  • Scan codebase — リポジトリ全体、または範囲を絞ったスキャン(ファイル数と相対コストが提示される)
  • Scan changes — ブランチの差分、PR の差分、単一コミットのスキャン
  • Suggest patches — レポートの検出結果から .patch ファイルを生成(適用は自分でレビューして実行)

マルチエージェント構成

複数の Claude エージェントがチームとして動作する。アーキテクチャの把握 → 脅威モデルの構築 → 脆弱性ハンティング → 独立レビューという分担で進み、検出結果は「到達可能性(REACHABILITY)・影響(IMPACT)・防御(DEFENSES)」の3観点の敵対的パネルで審査され、3票中2票以上を得たものだけがレポートに載る。

パブリックベータで追加された機能

  • 定期的な自動スキャンの実行(CI/CD パイプラインへの組み込み要望に対応)
  • 検出結果ごとの信頼度評価・再現手順・推奨パッチの一括表示
  • Claude Code への修正ハンドオフ(提案された修正を Claude Code で実装)

注意点・制限

  • 提案されたパッチは必ず人間のレビューが必要。自動マージの予定はなく、「AI がレビュー候補を出し、人間が判断する」ワークフローが前提
  • DAST(動的アプリケーションセキュリティテスト)の代替ではない。認証セッションの問題やレースコンディションなど、実行時の挙動に起因する問題は実アプリのテストが必要
  • ベータ版のため、対象プランや機能は今後変わる可能性がある
