---

- **D-0001** 2026-08-08 強制力は GitHub Actions に置く。Claude Code の hooks は
  リモートセッションで有効になるか公式に保証されていないため補強扱いとする。
  （その後、このリポジトリでは実際に動くことを確認した → D-0004）

- **D-0002** 2026-08-08 未マージだった4ブランチ（claude-security / translator /
  suno / desktop-cat、合計6,394行）を統合した。main は150日止まっていた。
  以後は放置せず autoflow で自動的に流す。

- **D-0003** 2026-08-08 `.github/` `.claude/` `tools/` `CLAUDE.md` を変える変更は
  自動マージしない。機械が自分を縛るルールを自分で書き換えられないようにするため。
  この制約は tools/automerge_gate.py の DENY 一覧が持っている。

- **D-0004** 2026-08-08 リモートセッションでも `.claude/settings.json` の hooks と
  `.claude/skills/` が有効になることを実測で確認した。公式ドキュメントには記載が無い。

- **D-0005** 2026-08-08 週次メンテナンスの Routine を作成した（毎週月曜 09:00 JST）。
  期限切れの「待ち」の `default:` 実行、ルールの棚卸し、検査の自動修正を無人で行う。

- **D-0006** 2026-08-08 自動マージは PR を経由せず main へ直接マージする方式にした。
  GitHub Actions が PR を作るにはリポジトリ設定の変更（人手）が必要で、
  「人を挟まない」という前提と両立しないため。保留するものは Issue で知らせる。

- **D-0007** 2026-08-08 仕組み一式（tools / .github / .claude / CLAUDE.md）を main に
  マージした。150日止まっていた main が動き、ここから自動処理が実際に効き始める。
  このマージだけは手作業。ゲートが自分自身を通さない設計なので、これは正しい動作。

- **D-0008** 2026-08-08 外部スクリプトの読み込みは ERROR ではなく WARN にする。
  translator.html は OCR に tesseract.js を CDN から読んでおり、これは正当な依存。
  ERROR にすると正しく動いているページのせいで公開経路が止まる。
  一方 `<base href>` と meta refresh は正当な用途が無いので ERROR のままにする。

- **D-0009** 2026-08-08 `.js` と入れ子の `assets/` も自動マージの対象に含める。
  HTML はインラインの `<script>` ごと通るので、同じコードを .js に切り出した
  瞬間だけ止めるのは防御になっていない。ブラウザゲームのブランチが
  breathless/js/audio.js 1本で永久保留になり、成果が溜まる元の状態に
  戻りかけたのが発見の契機。ページの中身の危険な書き方は check_site が見る。
