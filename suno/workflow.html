Suno運用ワークフロー

制作 → 公開 → SNS展開 の手順書とテンプレート

← トップ 楽曲管理

1. 週次の運用サイクル(推奨)

  1. 月曜: 新曲アイデア出し(1〜3件)→ 楽曲管理に「アイデア」として登録
  2. 火〜木: Sunoで生成・選定・リテイク(1曲あたり4〜8テイク目安)
  3. 金曜: ベストテイクを確定 → 下のリリースチェックリストを実施
  4. 土日: SNS展開(YouTube / X / TikTok)、反応の記録

週1曲ペースを想定した例です。ペースに合わせて調整してください。

2. プロンプトテンプレート集

基本形

[ジャンル], [ボーカル種別], [雰囲気・情景], [テンポ/BPM], [楽器の特徴]

J-Popバラード

emotional j-pop ballad, female vocal, piano and strings, nostalgic, 72bpm, building chorus

シティポップ / Synthwave

80s japanese city pop, dreamy synthwave, female vocal, night drive, funky bassline, 105bpm

ゲームBGM(ループ用インスト)

instrumental, loopable game bgm, [ステージの雰囲気], no vocal, seamless loop, consistent energy

リテイク時のコツ

  • 気に入ったテイクは Extend で伸ばす(丸ごと再生成より安定)
  • ボーカルの発音が崩れる場合は歌詞のカタカナ/ローマ字表記を試す
  • スタイル指定は3〜5要素まで。多すぎると平均化されてぼやける
  • 採用しなかったテイクのURLもメモ欄に残す(後で化けることがある)

3. リリースチェックリスト

  • ベストテイクを決定し、Sunoでタイトル・カバー画像を設定した
  • 歌詞の誤字・不自然な発音がないか最後まで通しで聴いた
  • Suno上の公開設定(Public/Private)を確認した
  • 音源をダウンロードしてバックアップした
  • suno/songs.json に楽曲情報を追加・更新した
  • 公開日とSuno URLを記録した

商用利用や外部配信をする場合は、契約中のSunoプランの利用規約(権利範囲)を必ず確認してください。無料プランは商用利用不可です。

4. SNS展開手順

YouTube

  • 静止画+音源の動画化(サムネはカバー画像を流用)
  • タイトル例: 【AI Music】曲名 / keelpop
  • 説明欄にSunoで制作した旨とジャンルタグを記載

X (Twitter)

  • 公開直後に告知ポスト(試聴リンク+ジャンル+一言コメント)
  • ハッシュタグ例: #Suno #AIMusic #AI音楽

TikTok

  • サビの15〜30秒を切り出してショート動画化
  • フックが強い曲を優先(全曲やらなくてよい)

5. 楽曲データの更新方法

suno/songs.json の songs 配列に1曲ずつ追加します。

{
  "id": 4,
  "title": "曲名",
  "status": "公開済み",        ← 公開済み / 制作中 / アイデア
  "genre": "ジャンル",
  "sunoUrl": "https://suno.com/song/...",
  "prompt": "使用したプロンプト",
  "releaseDate": "2026-08-01",
  "sns": { "youtube": false, "x": false, "tiktok": false },
  "memo": "自由メモ"
}

Claudeのセッションで「この曲を追加して」と曲情報を伝えれば、JSON編集からコミット・プッシュまで代行できます。
