# 残響 — Echo in the Dark

音の反響だけを頼りに暗闇を進む、スマホ向けブラウザホラーゲーム。
Dark Echo に着想を得た、ゼロから書き起こしのオリジナル実装。

**遊ぶ:** https://keelpop.github.io/echo/ （🎧 イヤホン推奨）

## あそびかた

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面をドラッグ（大きく倒すと走る） | WASD / 矢印キー、Shiftで走る |
| 手を叩く | 短くタップ | スペース |
| 一時停止 | 右上のボタン | Esc |

- 足音が波紋になって広がり、壁で反射して地形が浮かび上がる
- <span>赤い波</span>＝化け物。音を立てるほど寄ってくる。触れたら死
- <span>金の波</span>＝遺物と出口。遺物を全て拾ってから出口へ
- 水たまりは大きな音が出る。走るとさらに遠くまで届く

## 構成

```
echo/
  index.html      画面構成とUI
  css/style.css
  js/audio.js     Web Audio API による効果音の合成（音声ファイルなし）
  js/levels.js    ステージデータ（tools/genlevels.py が生成）
  js/game.js      ゲーム本体
```

外部ライブラリ・アセットは一切なし。すべて Canvas 2D と Web Audio で生成している。

### 音の表現

足音を出すたびに数十本の「音の粒子」を全方位へ飛ばし、壁で反射させながら
残像を残す。世界サイズのオフスクリーンキャンバスに毎フレーム薄い黒を重ねる
ことで、軌跡がゆっくり闇に沈んでいく。反射した瞬間の点だけ少し強く光らせて
いるので、壁面の形が読み取れる。

化け物はプレイヤーからは決して見えず、自分の足音（赤い波）だけが位置を伝える。
プレイヤーが立てた音の大きさに応じた半径で「聞こえ」、最後に音がした場所へ
BFSのフローフィールドを辿って向かってくる。

### ステージの編集

`echo/js/levels.js` は手で編集せず、`tools/genlevels.py` を書き換えて再生成する。
生成時に各ステージの寸法と「開始地点 → 遺物 → 出口」の到達可能性を検証している。

```sh
python3 tools/genlevels.py
```

記法: `#` 壁 / `.` 床 / `~` 水 / `P` 開始地点 / `E` 出口 / `*` 遺物 /
`M` 徘徊する化け物 / `S` 眠っている化け物
